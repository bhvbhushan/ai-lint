# Custom Rules & Presets

vibecop ships with a flexible configuration system that allows you to adjust rule severity, ignore specific patterns, and apply framework-specific presets out of the box.

## Using Framework Presets

To reduce configuration overhead and avoid false positives for framework-specific conventions, vibecop provides curated presets.

### SvelteKit Preset

SvelteKit uses special path aliases (`$lib`, `$app`, `$env`, `$service-worker`) that are resolved at build-time by Vite. By default, static analysis tools may flag these as `undeclared-import`.
